راهنمای نصب دستی — موتور محتوای هوشمند فاتح
================================================

این پوشه دقیقاً همون ساختاری رو داره که باید توی ریشه‌ی پروژه‌تون (E:\Project\fatehmusic)
کپی بشه. همه‌ی این ۳۲ فایل یا جدیدن یا نسخه‌ی نهاییِ فایل‌های تغییریافته.

مرحله ۱ — کپی فایل‌ها
----------------------
تمام محتوای این پوشه (به‌جز همین فایل راهنما) رو کپی کنید و روی پوشه‌ی
ریشه‌ی پروژه پیست کنید؛ وقتی ویندوز پرسید "Replace these files?"، بزنید Yes/Replace.
ساختار پوشه‌ها (src/ai/content-engine, src/pages/admin, tests/ai/... و غیره)
خودش می‌سازه و فایل‌های موجود (مثل README.md، package.json، worker.ts) رو
با نسخه‌ی جدید جایگزین می‌کنه.

مرحله ۲ — حذف دستیِ یک فایل قدیمی (مهم!)
------------------------------------------
این یک فایل رو خودتون دستی پاک کنید، چون در این روش (کپی مستقیم) امکان
"حذف خودکار" وجود نداره:

    src\server\ai-post-generator.ts

این فایل با src\ai\content-engine\article-generator.ts جایگزین شده.
اگه پاکش نکنید مشکلی برای build پیش نمیاد (چون هیچ‌جا دیگه import نمی‌شه)
ولی بهتره برای تمیز موندن ریپو حذفش کنید.

مرحله ۳ به بعد — همون مراحل قبلی
-----------------------------------
از اینجا به بعد دقیقاً همون چیزی که قبلاً گفته شد:

    npm install
    npm run db:migrate:local
    npm run db:migrate:remote
    wrangler secret put DEEPSEEK_API_KEY
    (deploy با فرآیند همیشگی‌تون)

بعدش برید /admin/topics و روی «تولید موضوعات جدید» بزنید.

تأیید صحت
----------
این دقیقاً همون فایل‌هاییه که قبلش با git apply روی یک کلون تازه از
گیت‌هاب تست شده و هر ۴۰ تست واحد (npm test) و build پروژه (npm run build)
بدون خطای جدید پاس شدن.
