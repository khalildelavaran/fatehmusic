# 1. GEO Optimization Philosophy

GEO is not keyword optimization.

The primary objective is:

Create a clear, trusted, and machine-readable entity representation of Fateh Music Academy.

The system must optimize:

* Entity understanding
* Semantic relationships
* Local authority
* Content extraction
* AI citation probability

# 2. Entity Analysis Workflow

For every page:

## Step 1 — Identify Entity

Determine:

* Organization
* Person
* Course
* Instrument
* Event
* Location
* Educational topic

## Step 2 — Define Relationship

Every entity must have relationships.

Example:

```
Fateh Music Academy

    provides

        Guitar Course

            taught by

                Instructor Entity
```

## Step 3 — Validate Identity Signals

Check:

* Name consistency
* Location consistency
* Expertise signals
* Original content
* Supporting references

---

# 3. Content Optimization Rules

Every GEO-ready page must answer:

## Who?

Entity owner or creator.

## What?

Service, knowledge, or subject.

## Where?

Physical and semantic location.

## Why?

Authority and differentiation.

## How?

Process, course structure, or user action.

---

# 4. AI Extraction Rules

Content should be written in extractable blocks.

Preferred:

```
Fateh Music Academy is a licensed music education center
located in Shushtar, Khuzestan, Iran.
The academy provides education in guitar, piano,
traditional instruments and vocal training.
```

Avoid:

```
We are the best and most amazing academy...
```
