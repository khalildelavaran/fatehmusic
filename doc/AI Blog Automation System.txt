# هدف پروژه

طراحی و پیاده‌سازی یک سامانه کاملاً خودکار مبتنی بر هوش مصنوعی که بدون دخالت انسان بتواند:

* کشف موضوعات مناسب برای تولید محتوا
* تحلیل رقبا
* تحلیل کلمات کلیدی
* تولید مقاله کاملاً سئو شده
* تولید تصاویر اختصاصی
* لینک‌سازی داخلی
* ساخت Schema
* انتشار در سایت
* مانیتورینگ عملکرد
* بروزرسانی خودکار مطالب

را انجام دهد.

هدف نهایی تبدیل سایت FatehMusic.ir به مرجع آموزش موسیقی فارسی و جذب ترافیک ارگانیک پایدار از گوگل است.

## 4- Topic Scoring Engine

فرمول نمونه:

```
Score =
(Search Volume × 0.35)
+
(Business Value × 0.30)
+
(Low Competition × 0.20)
+
(Search Trend × 0.15)
```

خروجی:

```
score.json
```

فقط موضوعاتی با امتیاز بالا منتشر می‌شوند.

# سیاست تولید محتوا

محتوا نباید:

* کپی باشد.
* ترجمه ماشینی باشد.
* Keyword Stuffing داشته باشد.
* اطلاعات ساختگی یا بدون منبع ارائه دهد.
* صرفاً برای موتور جستجو نوشته شود.

محتوا باید:

* برای انسان مفید باشد.
* پاسخ کامل به هدف جستجو (Search Intent) بدهد.
* در صورت نیاز جدول، مثال، تصویر و FAQ داشته باشد.
* با سایر صفحات سایت پیوند منطقی برقرار کند.

# هدف نهایی

ایجاد یک «AI Publishing Platform» که به‌صورت شبانه‌روزی محتوای تخصصی، باکیفیت و سئو‌محور تولید، منتشر و نگهداری کند؛ عملکرد هر مقاله را پایش نماید، در صورت افت رتبه آن را به‌روزرسانی کند و به مرور زمان سایت FatehMusic.ir را به مرجع آموزش موسیقی فارسی تبدیل کند. کیفیت، دقت، تجربه کاربری و رعایت اصول موتورهای جستجو باید در تمام مراحل، مهم‌تر از صرفاً افزایش تعداد مقالات باشد.
