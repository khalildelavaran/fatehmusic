# قرارداد گزارش پایان روز داشبورد روزانه

این سند قرارداد مرحله بعدی Command Center برای «بستن روز» آموزشگاه موسیقی فاتح است.

## هدف

گزارش پایان روز باید به منشی نشان دهد روز چه وضعیتی داشته و چه مواردی قبل از بستن روز باقی مانده‌اند؛ بدون اینکه UI دوباره منطق مالی یا وضعیت حضور را محاسبه کند.

## خلاصه روز

گزارش باید حداقل این شاخص‌ها را از Backend دریافت کند:

- تعداد جلسات برنامه‌ریزی‌شده
- تعداد جلسات انجام‌شده
- تعداد جلسات لغوشده
- تعداد هنرجویان یکتا
- تعداد هنرجویان یکتای حاضر
- تعداد حضورهای ثبت‌نشده
- تعداد حضور استادان ثبت‌نشده
- پرداخت‌های ثبت‌شده امروز
- مانده بدهی باز
- موارد معوق
- موارد نیازمند تمدید

## موارد باز قبل از بستن روز

این موارد باید به‌صورت actionable برگردند و هر مورد در صورت امکان به `session_id` یا شناسه رکورد دقیق متصل باشد:

1. حضور هنرجویان ثبت نشده
2. حضور استادان ثبت نشده
3. جلسات بدون اتاق
4. تداخل زمانی مدرس
5. تداخل زمانی اتاق
6. بدهی یا صورتحساب ناقص
7. موارد تمدید
8. جلسات لغوشده‌ای که نیازمند ثبت/بررسی علت هستند

## منبع حقیقت

- KPIهای یکتا فقط از `metrics` معتبر Backend مصرف شوند.
- وضعیت مالی، سررسید، معوقه و مانده فقط از Backend مصرف شوند.
- UI نباید برای بستن روز، مبلغ یا وضعیت مالی را دوباره محاسبه کند.
- UI نباید صرفاً بر اساس تعداد کارت‌های DOM نتیجه بگیرد که روز کامل شده است.

## وضعیت بستن روز

Backend باید یکی از وضعیت‌های زیر را برای گزارش برگرداند:

- `open` — روز هنوز باز است.
- `ready` — مورد بحرانی یا ثبت‌نشده‌ای باقی نمانده است.
- `needs_attention` — مواردی برای بررسی باقی مانده است.
- `closed` — روز توسط کاربر مجاز بسته شده است.

`closed` باید یک عملیات صریح و audit-able باشد؛ صرف نمایش گزارش نباید روز را ببندد.

## Audit

عملیات بستن روز باید حداقل شامل این اطلاعات باشد:

- کاربر انجام‌دهنده
- تاریخ عملیاتی مدرسه
- زمان ثبت عملیات
- وضعیت قبل و بعد
- خلاصه KPIهای لحظه بستن

## قاعده زمانی

تاریخ عملیاتی باید بر اساس timezone تنظیم‌شده آموزشگاه تعیین شود و به timezone مرورگر یا UTC وابسته نباشد.

## مرحله پیاده‌سازی

ابتدا endpoint خواندنی گزارش پایان روز و مدل `open/ready/needs_attention/closed` پیاده‌سازی شود. سپس UI گزارش و در نهایت mutation صریح `close day` اضافه شود.
